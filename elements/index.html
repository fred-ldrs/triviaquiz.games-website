About the Chemical Elements Trivia Quiz

What does the Elements Trivia Quiz cover?
Questions cover all 118 elements of the periodic table: element names and symbols, atomic numbers and masses, discoverers and discovery dates, element categories (metals, non-metals, noble gases), and real-world uses in science and industry.
Is the quiz suitable for students?
Yes — the Elements Quiz is an excellent study companion for chemistry students at school or university. It reinforces periodic table knowledge in a fun, interactive format. Questions range from easy (memorising symbols) to advanced (isotopes, electron configurations).
Is the Elements Trivia Quiz free?
Completely free. Play directly at elements.triviaquiz.games — no account or payment required.
Why is it labelled Beta?
The Elements Quiz is still in active development. More questions and features are being added regularly. Feedback and question suggestions are very welcome — use the Submit a Question form.
Can I play offline?
Yes. Install the PWA via the address bar install icon and the quiz runs fully offline. Ideal for studying without an internet connection.

About the Board Game Trivia Quiz

What topics does the Board Game Trivia Quiz cover?
Questions cover a wide range of tabletop gaming: classic board games, modern euro-games, deck-building games, role-playing games, famous designers, publishers, Kickstarter milestones, game mechanics, and board game history from Chess to Catan.
Is it suitable for casual players and hardcore fans alike?
Yes. Questions are spread across difficulty levels — from well-known classics that casual players will recognise to deep-cuts that challenge even the most dedicated board game enthusiasts.
Is the Board Game Trivia Quiz free?
Completely free. Play in the browser at boardgame.triviaquiz.games or download the Android app — no subscription required.
Can I play offline?
Yes. Install the PWA via the address bar install icon and all content is cached for offline use. Great for game nights without Wi-Fi. The Android app also works offline.
Can I add a board game trivia question?
Yes! Submit your question via the Submit a Question form. Community-approved questions are featured on the Community Questions page.
